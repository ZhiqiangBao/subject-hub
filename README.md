# 学科 Hub

给**老师和家长**用的十二年全科练习站。学生打开网页就能闯关、做作业、交卷；老师或家长组卷、看每一位学生每一次作答、改主观题。

不是刷题竞赛站，也不是编程评测。题目是语文、英语、数学、物理、化学、生物、历史、政治。一台家里或学校常开的电脑当主机，手机、平板、电脑连同一 Wi-Fi，浏览器打开即可。

学生不填 YAML、不写 LaTeX、不碰 API 密钥。交卷后只看见自己的分数，看不见同学成绩和名次。

编程练习请用 [leet-hub](https://github.com/ZhiqiangBao/leet-hub)。两套可以装在同一台机器上，账号和成绩分开。

## 学生

1. 连上主机所在的网络，浏览器打开 `http://<主机IP>:8090`
2. 自己注册、登录
3. 按科目闯关，或打开老师发来的试卷
4. 阅读题左边看材料、右边答题；数理化生填空可用根号、积分按钮，不必学公式代码
5. 在「我的成绩」里看自己做过的闯关和试卷

## 老师 / 家长

1. **只在主机本机**打开 `http://127.0.0.1:8091` 注册管理员（可以有多位）
2. 之后用同一套 `8090` 登录后台
3. 按科目、年级、知识点组卷，或让学生自由闯关
4. 测验里看匿名答卷、改主观分；分数出齐才能发布成绩。学生页等发布后才能看该生这一次
5. 加题：点「复制出题说明」，用普通人说话让聊天模型出题，把回复贴回网页入库

网页 8090 上的注册永远是学生，第一个注册的人也不会变成管理员。

## 题目从哪来

仓库里的 `bank/` 是跟代码一起走的题库。老师在网页上改过或新加的题只存在这台主机的 `data/` 里，更新代码时不会被覆盖。

知识点标签按义务教育课程标准（2022 年版）和普通高中课程标准（2017 年版 2020 年修订）梳理，见 [docs/curriculum-tags.md](docs/curriculum-tags.md)。

## 装机（给负责那台电脑的人）

评测机建议 Ubuntu。步骤见 [docs/host.md](docs/host.md)。

```bash
git clone https://github.com/ZhiqiangBao/subject-hub.git
cd subject-hub
chmod +x scripts/setup-ubuntu.sh scripts/run-ubuntu.sh scripts/update-from-github.sh
./scripts/setup-ubuntu.sh
```

学生端端口 **8090**（局域网）。管理员注册端口 **8091**（只绑本机，不要对网段开放）。

账号、成绩、本地改过的题、演算纸照片都在 `data/`，不进 Git。
