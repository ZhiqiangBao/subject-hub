## 怎么当标签用

1. 每题 `tags` 写 1～4 个，必须能在对应分册里找到（允许同义词，见各册「可视为同一标签」）。
2. 不要把科目、年级、难度、题型写进 `tags`。
3. 组卷、闯关按标签取 **交集**（选了多个就必须都带上）。
4. 高中先标必修主题，选考方向再加「选择性必修」下的标签。
5. 课标主题偏大（如「文学阅读与创意表达」）时，出题再落到分册里的细标签（如「记事」「写人」「古诗朗读」）。

主编与出题模型：只从这些分册选标签，不要自造课标里没有的考点名称。
