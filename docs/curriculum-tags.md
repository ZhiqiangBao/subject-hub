# 十二年知识点标签目录

出题、组卷、闯关用的 **知识点标签**（YAML `tags` 字段）。按课标主题梳理到可抽题的粒度，**不是课标全文**，不能单独作为题目内容或学段要求的依据。

## 对齐的文件

出题时先查对应课标 Markdown 正文，再从本目录选标签。官方通知、文件路由和本地全文索引见 [课标资料库说明](standards/README.md) 与 [课程标准索引](standards/INDEX.md)。

## 怎么当标签用

1. 每题 `tags` 写 1～4 个，必须能在对应分册里找到（允许同义词，见各册「可视为同一标签」）。
2. 不要把科目、年级、难度、题型写进 `tags`。
3. 组卷、闯关按标签取 **交集**（选了多个就必须都带上）。
4. 高中先标必修主题，选考方向再加「选择性必修」下的标签。
5. 课标主题偏大（如「文学阅读与创意表达」）时，出题再落到分册里的细标签（如「记事」「写人」「古诗朗读」）。

出题助手：先用 [课标资料库索引](standards/INDEX.md) 路由并阅读对应标准的课程目标、内容要求和学业质量，再用本目录选择标签。本站八科的 id 是 `chinese`、`english`、`math`、`physics`、`chemistry`、`biology`、`history`、`politics`；地理等其他课标可查阅，但当前不属于本站入库科目。不要自造本目录没有的标签，也不要把标签名称写成课标原文或某个具体年级的进度承诺。
