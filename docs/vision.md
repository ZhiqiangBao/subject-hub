# 学科 Hub · 远景规划

本文只记**以后可以做、现在不要做**的扩展。近期任务仍写在 [下一阶段计划](plan.md)。不要为这些条目改当前 Ubuntu 装机路径。

原则不变：学生始终用浏览器打开一台主机的 `8090`；不要每学生一份程序、不要在学生页填密钥。

## 启动方式（可执行程序 / 一键客户端）

现在正式装机是 Ubuntu + systemd。程序本身是 FastAPI + SQLite，并不绑死 Linux。以后可以把**服务端**收成点一下就跑：

- Windows / macOS 可执行文件：后台拉起 8090（局域网）和 8091（仅本机），再用系统浏览器打开管理员登录页。
- Python wheel（`.whl`）：给已有 Python 的机器 `pip install` 后一条命令启动；运行时不再要 Node（前端预先打进包）。
- 托盘图标、关窗口不杀进程、开机自启：都是启动壳，不改判题。

`data/` 必须落在可写目录，不能写进只读安装包。8091 仍只绑本机。杀毒软件可能拦未签名的 exe，家庭分发时要单独考虑。

## 运行环境

| 角色 | 远景 | 现在不要当成正式方案 |
| --- | --- | --- |
| Ubuntu 主机 | 继续作为家庭/学校常开评测机 | — |
| Windows 本机当主机 | 源码已能跑；以后用 exe / 服务替代命令行 | 不要先做安装器 |
| WSL | 开发、试用可以 | 不要当家里常开主机（端口、休眠） |
| 手机 / 平板 | 继续当**浏览器客户端**连 8090 | 不要当服务端（休眠、IP、后台限制） |
