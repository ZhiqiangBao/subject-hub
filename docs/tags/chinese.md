# 语文标签 · chinese

依据：《义务教育语文课程标准（2022年版）》六大学习任务群 + 四学段；《普通高中语文课程标准（2017年版2020年修订）》学习任务群。

细标签按学段给，便于 `grade` 与 `tags` 一起用。任务群名称可作粗标签，出题优先用细标签。

## 义务教育任务群（粗标签，1～9 年级都可用）

- 语言文字积累与梳理
- 实用性阅读与交流
- 文学阅读与创意表达
- 思辨性阅读与表达
- 整本书阅读
- 跨学科学习

贯穿主题（可与细标签并列）：中华优秀传统文化、革命文化、社会主义先进文化。
