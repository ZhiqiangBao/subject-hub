# 政治标签 · politics

本站 `politics` = 义务教育 **道德与法治** + 普通高中 **思想政治**。

依据：《义务教育道德与法治课程标准（2022年版）》核心素养与学段内容；《普通高中思想政治课程标准（2017年版2020年修订）》必修与选择性必修模块。

## 核心素养方向（粗标签，1～12 可用）

- 政治认同
- 道德修养
- 法治观念
- 健全人格
- 责任意识

高中课标用语对应：政治认同、科学精神、法治意识、公共参与。出题可与上列并存，不要混成一串。
