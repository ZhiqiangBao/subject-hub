# 物理标签 · physics

依据：《义务教育物理课程标准（2022年版）》三个一级主题（物质、运动和相互作用、能量）+ 实验探究 + 跨学科实践；《普通高中物理课程标准（2017年版2020年修订）》必修与选择性必修模块。

义务教育物理多从八年级开设，标签仍标在 7～9 学段，出题 `grade` 用 8 或 9。
