# 数学标签 · math

依据：《义务教育数学课程标准（2022年版）》四领域、四学段；《普通高中数学课程标准（2017年版2020年修订）》五条主线。

**2022 相对旧小学课标的落点（出题必须遵守）：** 负数、方程、反比例函数的系统学习在 **第四学段（7～9）**；小学第三学段综合与实践可出现负数主题活动，但不要把「一元一次方程」「反比例函数」标成 5～6 年级知识点。小学「数与代数」只有 **数与运算、数量关系** 两个主题。
