常生活相关的语音材料，潜移默化地使学生对语音材料产生条件反

3. 说

4. 读
阅读分为朗读和默读两种形式。教师应重视培养学生的朗读能

5. 写
写作是一项精确而严谨的表达技能。教师应注重培养学生对文
体类型的辨别能力，帮助学生通过分析阅读材料和积累阅读量，逐

书写习惯，帮助他们打下扎实的书面表达基本功，包括掌握拼写规
则、正确使用标点符号和书写美观等，引导他们注意纠正语句中的
简单错误，形成严谨的态度和良好的习惯。
6. 词汇知识
教师应引导学生不拘泥于教材或词典对单词的释义，而是将词汇

上下文理解词汇含义的习惯，掌握准确领会词义和使用词汇的方法。
