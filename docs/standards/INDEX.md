## 检索与引用

对应 Markdown 与源 PDF 同名，只改扩展名。转换文档保留 `## PDF 第 N 页` 页界标记，并记录源文件 SHA 与版本。示例：

```sh
rg -n -C 8 --glob '*.md' '一次函数|函数图象|方程' '义务教育-2022/04-义务教育数学课程标准（2022年版）.md'
```

用 `-C` 查看命中内容的上下文并确认章节和页标记；只有页码或孤立行号不足以支持出题。义务教育全文由扫描版 PDF OCR 得到，复杂表格、图示、公式、罕见字或语义不通的段落应回查本地原 PDF。版本、SHA 与 OCR 边界见 [README](README.md)。
