## 自动结构与原生文本检查

执行入口是 [`scripts/verify_standards.py`](../../scripts/verify_standards.py)。从项目根目录、在可导入 `pypdf` 的 Python 环境中，且本地源 PDF 放在 `docs/standards/` 时运行：

```sh
python scripts/verify_standards.py --report tmp/pdfs/standards-verification.json
```

源 PDF 放在其他目录时，使用 `--source-root "<PDF目录>"` 指定来源；转换后的 Markdown 可通过 `--standards-root` 指定。

脚本读取 `docs/standards/conversion-manifest.json`，检查 PDF/Markdown 与清单的文件对应、路径边界、源 PDF SHA、总页数、连续且完整的 PDF 页标记，以及文字层页的 Markdown 内容与源 PDF 提取文本是否一致；还要求转换批次的 `run_status` 为 `complete`，并逐一核实 `ocr-corrections.json` 中按源 SHA 和 PDF 页码记录的校正文本已出现在对应 Markdown 页。报告中的 `passed` 只表示这些自动检查没有失败；仍须阅读 `documents_with_quality_notes` 和 `quality_notes`，因为清单质量提示不会自动让 `passed` 变为失败。
