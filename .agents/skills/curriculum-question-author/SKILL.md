# 课标辅助出题

为本站生成题目或审校题目时，先核对用户给出的**年级、科目、知识点**，再查对应课程标准全文。不能只根据 `docs/curriculum-tags.md` 或既有教材经验推断课标要求。

## 查找课标

从本 skill 所在目录向上找到项目根目录（其中有 `docs/standards/INDEX.md`），或使用当前工作区中该索引的路径。不要依赖某台电脑的绝对路径。若索引或对应全文没有随工作区提供，说明无法查证，并请求可读的课标文件；不要假装已检索。

1. 将年级 1～9 路由到 `义务教育-2022/`，10～12 路由到 `普通高中-2017-2020修订/`。年级或科目无法从上下文确定时，先问清再出题。
2. 按 `docs/standards/INDEX.md` 的科目名、别名和本站科目 id 选对应全文。先读目录中该科的“课程目标／内容要求”，再读相关主题所在部分及“学业质量”（各课标具体标题可能略有差异）。
3. 用中文主题词和近义词检索，并读取命中处前后文，确认完整的小节及 `## PDF 第 N 页` 页标记。例如：

   ```sh
   rg -n -C 8 --glob '*.md' '一次函数|函数图象|方程' 'docs/standards/义务教育-2022/04-义务教育数学课程标准（2022年版）.md'
   ```

   检索“学业质量”和相关要求时也可用 `rg -n -C 8 '学业质量|学业要求|内容要求|课程目标' <对应文件.md>`。多词用 `-e` 或 `|` 组合；使用中文词组，避免把宽泛词拆成单字。
4. 用命中的具体要求确定题目考查内容、情境、认知要求和难度。引用或记录依据时写仓库内 Markdown 源路径及其对应 **PDF 页码**（如 `docs/standards/义务教育-2022/04-…md，PDF 第 42 页`）；不要只给搜索行号，也不要在学生题干中塞入出处。

## 年级与课程边界

- 课程标准通常规定学段或主题要求，不保证某知识点安排在某个年级、学期或教材章节。若课标未细分到指定年级，应明确这是学段要求，不得编造年级进度、教材版本或章节；按用户给出的教材/进度约束出题，缺少关键约束时先询问。
- 小学不设独立物理、化学、生物学、历史课。小学科学启蒙查义务教育科学课标，不把初中分科课标倒套到小学；需要网站单科入库而课程不匹配时说明限制。
- 义务教育英语课标允许一年级起始的条件式安排；1～2 年级英语不是默认统一必修。只有用户明确指定相应英语学习安排时才按英语出题。
- 网站当前题库八科 id 为 `chinese`、`english`、`math`、`physics`、`chemistry`、`biology`、`history`、`politics`。政治在义务教育对应“道德与法治”，高中对应“思想政治”。地理等其他标准可在资料库检索，但不要伪装成本站可入库科目。

## 生成并自检

- 在网站管理员「加题」页使用「AI出题」生成预览；模型地址、密钥、模型名与思考设置统一由管理员「模型」页管理，出题和主观题评分复用该配置。请求可生成 1～5 题，预览题可编辑后逐题确认入库。题目来源返回的 `path`、`pages`、`stage` 用于核对依据；义务教育文本经过 OCR，复杂表格、公式或 OCR 结果含糊时回查对应 PDF。
- 题目字段与格式以 [`docs/author-bank-skill.md`](../../../docs/author-bank-skill.md) 为准；不要在本 skill 重复一份 schema。知识点标签另查 [`docs/curriculum-tags.md`](../../../docs/curriculum-tags.md)，它是标签目录，不是课标原文。先以课标决定考查要求，再选最贴切的现有标签；不要自造标签或将大主题标签误当具体要求。
- 题目必须原创，不照搬教材课文或真卷。生成后逐题核对答案与解析、选项唯一性、分值和题型结构，并确认每个考查点都被所引课标内容支持；发现错误先修订预览再入库。
